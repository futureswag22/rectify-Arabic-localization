# Rectify Arabic Localization Project

Arabic subtitle localization project for **Rectify Seasons 1 and 2**.

This project includes a complete revision and localization of the Arabic subtitles across both seasons, with a focus on natural dialogue, linguistic accuracy, subtitle readability, timing refinement, consistency management, and quality control.

## Project Scope

The project covers all episodes of Seasons 1 and 2 and includes:

* Translation revision
* Dialogue localization
* Cultural adaptation
* Waveform-based timing refinement
* Reading speed optimization
* Text segmentation and line-break review
* Grammar and punctuation correction
* Consistency management
* Linguistic review
* Final quality control (QC)

## Workflow

This project was completed using a human-in-the-loop localization workflow.

AI-assisted draft translations were used as an initial reference in selected cases. All localization decisions, dialogue adaptation, timing refinement, subtitle editing, linguistic review, consistency management, and final quality control were performed manually.

The final subtitles reflect human editorial judgment throughout the entire localization process.
