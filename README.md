# Rectify Arabic Localization Project

Arabic subtitle localization project for Rectify Seasons 1 and 2.

This project includes a complete revision of the Arabic subtitles for all episodes across both seasons, with a focus on natural dialogue, linguistic accuracy, timing refinement, consistency management, and quality control.

## Technical Details

Source:
BluRay H.265 releases

Work Included:

* Translation revision
* Dialogue localization
* Waveform-based timing refinement
* Grammar and punctuation correction
* Consistency review
* Final QC pass

## Project Statistics

* Seasons: 2
* Episodes: 16
* Source Format: BluRay H.265
* Language: Arabic
